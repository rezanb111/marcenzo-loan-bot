# Media banners

Put optional JPG/PNG files here to show images in the bot:

| File | Section |
|------|---------|
| `welcome.jpg` | Language / start |
| `main_menu.jpg` | Main menu |
| `loan.jpg` | Request loan |
| `profile.jpg` | Profile |
| `support.jpg` | Support |
| `admin.jpg` | Admin panel |
| `success.jpg` | Loan success |

If a file is missing, the bot still works with text only.

Recommended size: **800×400** or **1200×600**, landscape, soft gradient fintech style.
